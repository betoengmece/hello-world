# Ateliê Kanto — conceitos SVG da geração 1

30 espécies adicionais, com 3 versões cada (90 SVGs independentes, transparentes, viewBox 0 0 230 220). Nenhuma espécie já cadastrada em js/data.js foi repetida.

Abra index.html nesta pasta para comparar, buscar por nome, escolher uma versão por espécie e exportar escolhas em JSON. A galeria funciona sem dependências; é possível abrir localmente após baixar o ramo.

- V1: fofa, cabeça maior e corpo compacto.
- V2: combate, postura inclinada e expressão determinada.
- V3: clássica, linhas mais finas e luz.

Os arquivos são estudos visuais originais de fã. Não estão integrados ao jogo, não possuem regras de combate ou animações e não alteram js/art.js, js/data.js ou a página do jogo. Pokémon pertence a Nintendo / Game Freak / Creatures.

Espécies: Venusaur, Charizard, Blastoise, Beedrill, Raichu, Sandshrew, Ninetales, Jigglypuff, Vileplume, Dugtrio, Meowth, Psyduck, Arcanine, Alakazam, Machamp, Rapidash, Slowbro, Magneton, Gengar, Exeggutor, Cubone, Scyther, Electabuzz, Magmar, Pinsir, Lapras, Eevee, Vaporeon, Jolteon, Snorlax.
